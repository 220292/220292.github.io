Mẹo Ghi Nhớ Nhanh 7 Tầng OSI & Đối chiếu TCP/IP

Từ Tầng 1 → Tầng 7 (Dưới lên)

"Please Do Not Throw Sausage Pizza Away"

  • Please → 1. Physical (Vật lý)
  • Do → 2. Data Link (Liên kết dữ liệu)
  • Not → 3. Network (Mạng)
  • Throw → 4. Transport (Giao vận)
  • Sausage → 5. Session (Phiên)
  • Pizza → 6. Presentation (Trình diễn)
  • Away → 7. Application (Ứng dụng)
Từ Tầng 7 → Tầng 1 (Trên xuống)

"All People Seem To Need Data Processing"

  • All → 7. Application (Ứng dụng)
  • People → 6. Presentation (Trình diễn)
  • Seem → 5. Session (Phiên)
  • To → 4. Transport (Giao vận)
  • Need → 3. Network (Mạng)
  • Data → 2. Data Link (Liên kết dữ liệu)
  • Processing → 1. Physical (Vật lý)

Cách nhớ Đơn vị dữ liệu (PDU) từ Tầng 7 xuống Tầng 1:

L7-L5: Data L4: Segment / Datagram L3: Packet L2: Frame L1: Bit (0/1)
